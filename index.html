01 — À propos

Étudiant en MMI,
passionné par le web.

En 1ère année de BUT MMI à l'IUT de Troyes (parcours Développement Web), je développe des applications web de bout en bout — conception de bases de données SQL, logique serveur, intégration front-end. Mon approche est celle d'un développeur fullstack : je pense autant à l'architecture qu'au rendu.

Ce qui me motive profondément, c'est la création de programmes où le code devient vecteur de narration. L'interactivité permet des récits impossibles ailleurs — des histoires où chaque choix a un poids, où l'utilisateur n'est pas spectateur mais acteur. C'est cette logique — structurer l'invisible pour que l'expérience soit fluide — qui nourrit aussi mes projets plus utilitaires : construire un back-end solide ou une base de données bien pensée, c'est le même travail d'architecture au service d'une expérience.

Je cherche une alternance à partir de 2026 pour apporter autant qu'apprendre, dans une équipe où les projets ont du sens.
