Projet 02

Application CRUD Dynamique.

Type Gestion de base de données
Stack PHP / SQL / CSS
Focus Backend & Interface Admin
Interface Utilisateur

Page d'accueil : Un design accueillant et coloré utilisant des gradients et des ombres douces pour une expérience utilisateur moderne et accessible.

Le brief.

Développement d'une plateforme de gestion de films d'animation. L'enjeu était de créer une interface capable de communiquer en temps réel avec une base de données SQL pour afficher, ajouter, modifier ou supprimer des entrées.

Architecture CRUD.

Ce projet m'a permis de mettre en place un système complet de gestion (Create, Read, Update, Delete). J'ai conçu un back-office sécurisé permettant d'administrer le catalogue de films de manière intuitive.

Dashboard : Vue d'ensemble du catalogue avec récupération dynamique des données (ID, Durée, Réalisateur, Studio).

Contrôle des données : Mise en place des boutons d'action (Modifier/Supprimer) liés directement à la logique serveur.

Ajout de contenu : Formulaire structuré pour l'injection de nouvelles références dans la base SQL.

Édition : Interface de mise à jour permettant de modifier les informations existantes (ici l'exemple de Shrek).
